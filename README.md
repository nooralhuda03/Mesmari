# مسماري — تطبيق المعلم

تطبيق فلتر لمنصة مسماري التعليمية، جهة المعلم. الواجهات مبنية على تصميم Figma.

## المتطلبات
- Flutter 3.35 أو أحدث
- اتصال انترنت بأول تشغيل (الخطوط تنزل من Google Fonts)

## التشغيل
```bash
flutter pub get
flutter run
```

## البناء
```bash
flutter build apk --release      # اندرويد
flutter build ipa                # ايفون (يحتاج ماك و Xcode)
flutter build web                # ويب
```

## الهيكل
```
lib/
├── main.dart              نقطة البداية
├── app/                   التطبيق، المسارات (routes)، وشريط التبويبات
├── features/              كل ميزة بمجلد: data (البيانات) + presentation (الشاشات)
│   ├── home/  courses/  quiz/  students/
│   ├── questions/  meetings/  certificates/  profile/
└── mesmari_shared/        الحزمة المشتركة مع تطبيق الطالب
    ├── assets/icons/      ايقونات SVG مصدّرة من Figma
    └── lib/
        ├── core/          الالوان، الخطوط، الويدجتات، الترجمة، المسارات
        └── features/      تسجيل الدخول، الشات، الاشعارات، الملف الشخصي، المشغل
```

## الشاشات
تسجيل الدخول، إنشاء حساب، رمز التحقق، الرئيسية، كورساتي، ادارة الكورس،
كورس جديد، تعديل/اضافة محاضرة، محرر الاختبار، طلاب الكورس (تعيين الكورسات)،
متابعة الطلاب، ارسال تذكير، الاسئلة، الاجتماعات وجدولتها، الاجتماع المباشر،
التقارير والشهادات، الارباح، الاشعارات، المحادثات، الملف الشخصي والاعدادات.

## تعيين الكورسات للطلاب
المعلم هو اللي يحدد منو ياخذ أي كورس: ادارة الكورس ← **طلاب الكورس**.
الكود: `mesmari_shared/lib/features/enrollment/`.

## اللغة
عربي وانكليزي. التبديل من: الملف الشخصي ← اللغة، أو من زر (عربي | English)
بصفحة الدخول. النصوص كلها بملف واحد:
`mesmari_shared/lib/core/l10n/app_strings.dart` — تضيف مفتاح جديد هيچي:
```dart
'my_key': (ar: 'النص بالعربي', en: 'English text'),
```
وتستخدمه بالشاشة: `tr('my_key')`

## البيانات
كل البيانات حالياً وهمية وبالذاكرة (`features/*/data/`). لما تربط الـ API،
بدّل محتوى ملفات الـ repository بس — الشاشات ما تحتاج تعديل.

## الأيقونة واسم التطبيق
أيقونة التطبيق هي شعار مسماري (المسمار) على خلفية بلون الهوية، ومولّدة لكل
المقاسات (أندرويد، iOS، ويب).

لتغييرها: عدّل `mesmari_shared/assets/icons/logo.svg` أو الألوان بملف
`mesmari_shared/tool/generate_app_icons.dart`، وبعدين:
```bash
cd mesmari_shared && flutter test tool/generate_app_icons.dart
```
راح يطلع لك ملف PNG بمقاس 1024، وبعدها تحدّث المقاسات بأمر `sips` أو بحزمة
`flutter_launcher_icons`.

اسم التطبيق اللي يظهر تحت الأيقونة موجود بـ:
- أندرويد: `android/app/src/main/res/values/strings.xml`
- آيفون: `ios/Runner/Info.plist` (المفتاح `CFBundleDisplayName`)

## الوضع الليلي والنهاري
من: الملف الشخصي ← **المظهر** — فاتح، داكن، أو حسب النظام.

كل الألوان تتغير تلقائياً لأنها معرّفة بمكان واحد:
`mesmari_shared/lib/core/theme/app_colors.dart` — كل لون اله نسخة فاتحة
ونسخة داكنة. إذا تريد تغيّر أي لون، غيّره هناك بس.

الحالة محفوظة بالذاكرة (`core/theme/theme_controller.dart`)، يعني ترجع
للوضع الفاتح إذا سكرت التطبيق. للحفظ الدائم استخدم `shared_preferences`.
